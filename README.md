# lucas-rus/homebrew-tap

Homebrew formulae for [Concord](https://github.com/lucas-rus/concord) — contract-level coherence and smart merging for parallel AI coding agents.

```bash
brew install lucas-rus/tap/concordmcp
concord setup
```

## concord-team

See what your teammates' AIs are changing, while they change it:

```bash
brew install lucas-rus/tap/concord-team
```
